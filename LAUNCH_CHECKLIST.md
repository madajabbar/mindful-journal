## 🛠 **TROUBLESHOOTING GUIDE**

### **Common Issues & Solutions**

#### **1. App Won't Run**
```bash
# Clean and rebuild
flutter clean
flutter pub get
flutter run -d chrome
```

#### **2. Database Errors**
```bash
# Generate adapters
dart run build_runner build --delete-conflicting-outputs

# Check models
flutter analyze
```

#### **3. Build Failures**
```bash
# Check Android setup
flutter doctor

# Build debug version
flutter build apk --debug
```

#### **4. Play Store Rejection**
- **Privacy Policy**: Must be accessible
- **Age Rating**: Must be accurate (12+)
- **Screenshots**: Must match actual app
- **Description**: Must be accurate
